# Overarching project

Let's create a nice project that will be carried over through lessons.

You can create whatever inspires you but, since it has been already shown in the Python I course, I suggest building some code that processes images (the example I will provide builds on this idea).
Sticking to this theme, you can for example create methods to load, show, resize, edit and image.

Do what you'd like and be creative :)

## Lesson 1: Classes

Build a hierarchy of classes to handle your project.
In the image processing example, you can write for example a class that handles data of jpeg images, loading them and editing them somehow.

## Lesson 2: Errors and testing

Add error handling and fool-proof the class code you wrote for the previous point.
Also write some test and check you code passes them.

## Lesson 3: Modules

Wrap your classes in a package, adding for example some other module containing functions that act on said classes.
Install it locally with pip.
